# reports/

Отчёты `npm run ai:compare` — сравнение шаблонной и ИИ-версий текста на
реальных запросах к модели. Каталог отслеживается git-ом (в отличие от
`out/`): отчёт о платном прогоне воспроизводится только повторной тратой
кредитов, а у игнорируемого каталога нет ни истории, ни отката.

Файлы вида `compare-<дата>-<модель>.md` коммитятся как обычные файлы —
удалять вручную, если реально не нужны, не полагаясь на автоматическую
уборку (в отличие от `out/`, для `reports/` её нет и не должно быть).
