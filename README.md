# morning-post

Одноразовый скрипт: раз в день берёт снапшот роя монет и скриншот графика с
inp.one (`window.__HOT_COINS_SNAPSHOT__`, флаг `?snapshot=1`), собирает пост по
шаблону (без ИИ в v1) и публикует его в Telegram.

Статус: в разработке, см. `plan/Start-build.md`. Инструкции по запуску,
переменным окружения и деплою появятся здесь по мере готовности пайплайна
(шаги 4–6 плана).

## Пока готово

- Контракт `HotCoinsSnapshot` (`src/types.ts`) — копия того, что пишет `inp`.
- `SNAPSHOT_FILE`-режим (`src/snapshot.ts`) — загрузка и валидация снапшота из
  файла вместо браузера.
- Фикстуры снапшота (`fixtures/*.json`): `real-day.json` — снапшот с боевого
  сайта (дословно, не трогать). Остальные — его правленные копии, пересобираются
  из него скриптом `tools/gen-fixtures.mjs` (`npm run fixtures:gen`):
  red-стрик, red-первый день, green, mixed, boring, без BTC, без edge-пинов,
  граница `red/total == 0.6` ровно, тикеры `A&B`/`<b>X` для теста `escapeHtml`.
- Фикстуры истории (`fixtures/history/*.json`) — сценарии для `streak` в
  `computeFacts`: пустая история, один/три красных дня подряд перед сегодня,
  смена зелёный → красный, дыра в истории (пропущенный день обрывает стрик).
  Даты подобраны под `fixtures/red-streak.json` (2026-08-18 МСК = «сегодня»).

```bash
npm i
npm run typecheck
npm test
npm run fixtures:gen   # пересобрать производные фикстуры из real-day.json
```
